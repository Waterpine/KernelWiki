## Summary

Improves CUTLASS FMHA on Blackwell through two changes: bounding the causal masked-trip count to avoid empty tiles, and skipping correction rescaling when every lane observes a scale of 1.0. The author reports up to 1.5x acceleration for the affected long-context causal case.

## Problem

The CUTLASS FMHA implementation processed avoidable empty causal tiles and performed correction rescaling even when the warp did not need it.

## Solution / Techniques

- Bounded the causal trip count in `fmha_fusion.hpp` to skip empty tiles
- Added skip correction rescaling optimization in `sm100_fmha_fwd_mainloop_tma_warpspecialized.hpp` when scale == 1.0
- The causal mask fix eliminates wasted cycles on tiles that contain no valid attention entries
- The rescaling skip removes unnecessary work in the CUTLASS FMHA warp-specialized mainloop

## Key Code

```cpp
// Skip correction rescaling when scaling factor is 1.0
// in sm100_fmha_fwd_mainloop_tma_warpspecialized.hpp
if (scale != 1.0f) {
    // Apply correction rescaling
    apply_correction_rescale(acc, scale);
}
// Saves ~60 TFLOPS/s overhead for long context
```

## Performance

- Skip correction optimization: 60 TFLOPS/s improvement for long context scenarios
- Causal attention fix: approximately 1.5x acceleration for long context by eliminating wasted computation on empty tiles
- Combined effect improves the CUTLASS FMHA path for the reported causal-attention workloads
