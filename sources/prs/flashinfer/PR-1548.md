## Summary

Enables SplitK and makes the autotuner more robust for TensorRT-LLM's fused MoE FP4 implementation in FlashInfer. The patch also enables autotuning in the fused-MoE test path.

## Problem

The TRT-LLM fused MoE FP4 path needed SplitK support and more robust handling when autotuner tactic discovery failed or produced invalid SplitK configurations.

## Solution / Techniques

- Enables SplitK for the TRT-LLM-gen fused MoE path.
- Catches failures while retrieving valid autotuner tactics.
- Validates padded per-CTA K work for SplitK configurations.
- Enables the autotuner during the fused-MoE test warmup.
